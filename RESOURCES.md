# Resources: LLM chat systems

## Primary

- [Attention Is All You Need](https://arxiv.org/abs/1706.03762) — the paper that introduced the Transformer architecture; useful for understanding the model's core mechanism.
- [Vercel AI SDK: Chatbot tool usage](https://ai-sdk.dev/docs/ai-sdk-ui/chatbot-tool-usage) — practical reference for streaming chat UIs and displaying tool calls.
- [OpenAI Responses streaming reference](https://platform.openai.com/docs/api-reference/responses-streaming) — an example of server-sent incremental model output.

## Why these are here

The paper explains the model; the SDK guide explains the browser interaction; the API reference explains the streaming boundary between backend and UI.
